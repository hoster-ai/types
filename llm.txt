# hoster.ai Types Library - LLM Reference

This file serves as an index to the detailed documentation for each component.
Each entry links to a separate file containing the full code and details.


## DTOS

### AddonFieldDto
**Description:** Fields defined by the seller for a product, requested during checkout setup. Wraps a concrete field DTO under .field (an AnyFieldDto).

**Source:** `dtos/addon-field.dto.ts`

**Details:** See [llm/dtos/addonfielddto.md](llm/dtos/addonfielddto.md)

---

### AnyFieldDto
**Description:** Discriminated union of every concrete field DTO. Discriminator is the string-literal `type` property. Also exports FIELD_DTO_CLASSES runtime registry.

**Source:** `dtos/fields/any-field.dto.ts`

**Details:** See [llm/dtos/anyfielddto.md](llm/dtos/anyfielddto.md)

---

### AttachmentDto
**Description:** DTO for file attachments Used for sending attached files with emails

**Source:** `dtos/attachment.dto.ts`

**Details:** See [llm/dtos/attachmentdto.md](llm/dtos/attachmentdto.md)

---

### AttributeFieldDto
**Description:** Wraps a concrete field DTO (.field: AnyFieldDto) with product-attribute-specific options (visibleInOrder, visibleInClientPanel, repeatableMin/repeatableMax). Uses @AllOrNoneProperty and @MinLessOrEqualMaxProperty.

**Source:** `dtos/attribute-field.dto.ts`

**Details:** See [llm/dtos/attributefielddto.md](llm/dtos/attributefielddto.md)

---

### BaseFieldDto
**Description:** Abstract base for every concrete field DTO. Carries id, label, required, disabled, hidden, triggersRemoteValidation, remoteValidationErrorMessage, upgradable, downgradable.

**Source:** `dtos/base-field.dto.ts`

**Details:** See [llm/dtos/basefielddto.md](llm/dtos/basefielddto.md)

---

### BaseResponse
**Description:** Base response class Used as a foundation for all API responses

**Source:** `dtos/base-response.dto.ts`

**Details:** See [llm/dtos/baseresponse.md](llm/dtos/baseresponse.md)

---

### BaseInvoiceRequestDto
**Description:** Common payload of every document request sent to invoice integrations. Amounts are decimal major units, 2dp (not cents); the lines sum to netTotal and vatTotal, and totalAmount = netTotal + vatTotal.

**Source:** `dtos/invoice/requests/base-invoice-request.dto.ts`

**Details:** See [llm/dtos/baseinvoicerequestdto.md](llm/dtos/baseinvoicerequestdto.md)

---

### ClientDataDto
**Description:** Defines the data structure for a client. This object is used to transfer client data between different parts of the application.

**Source:** `dtos/client-data.dto.ts`

**Details:** See [llm/dtos/clientdatadto.md](llm/dtos/clientdatadto.md)

---
